# Intake checklist

## Business

- [ ] Primary conversion action
- [ ] WhatsApp / phone / CRM routing
- [ ] Markets served (local / diaspora)
- [ ] Payment plan rules summary

## Inventory

- [ ] Project list with slug, location, type, status
- [ ] Verified prices and currencies
- [ ] Beds / baths / areas with units
- [ ] Last-updated dates
- [ ] Forbidden placeholder patterns (e.g. repeated 95 sqft)

## Spatial

- [ ] Masterplan / survey drawings
- [ ] Plot polygons or CAD layers with stable IDs
- [ ] Lat/long + true north
- [ ] Floor plans / IFC / SketchUp / GLB
- [ ] Accuracy target per asset

## Legal / brand

- [ ] Legal entity name and address
- [ ] Privacy / terms counsel review
- [ ] Logo SVG, photography, awards proof
- [ ] Leadership bios
